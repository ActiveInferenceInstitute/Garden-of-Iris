# Abstract

Garden-of-Iris records an experimental approach to organising community discourse for language-model tooling. Its FourThought taxonomy distinguishes predictions, reflections, statements and questions by temporal orientation and epistemic role. A repository review traces how this scheme enters Discord interactions, historical text processing and summarisation. The runnable components establish a method for formatting and transforming records. The available artifacts establish neither a trained Iris model nor predictive validity for the taxonomy [@source].

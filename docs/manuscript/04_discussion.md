# Discussion

A reproducible extension of this study would specify the collection window, store an export version and publish a codebook for borderline cases. A held-out set that records both the assigned tag and the reviewer rationale would allow category agreement to be measured without using model output as the reference. Evaluation of future-oriented assertions would additionally need a dated observation protocol. These are conditions for a subsequent study. The current result is a traceable description of the artifacts available for such a study.
